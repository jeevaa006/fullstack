## Technical concepts to be ready to explain

All members should be prepared to describe:

1. React component state, forms, routing, shared context, Axios and the Vite development proxy.
2. REST resource design, HTTP methods/status codes, Express middleware, payload validation and centralized errors.
3. MongoDB documents, Mongoose schemas/references, model validation, indexes and database connection health.
4. bcrypt password hashing, HttpOnly JWT cookies, expiration, cookie/CORS settings and why browser roles are not trusted.
5. Role-based authorization and record ownership checks, including patient/doctor appointment privacy.
6. Appointment status transitions, slot availability and how MongoDB's partial unique index prevents concurrent duplicate active bookings.
7. Doctor verification and the distinction between public listings and pending/rejected profiles.
8. Environment variables, admin bootstrap, test isolation and limitations of memory-server tests.
9. Medical disclaimer, reminder boundaries, non-diagnostic guidance and why no clinical claims are made.
10. What is not implemented (maps, asynchronous notifications, and real online consultations) and how these could be added responsibly.
